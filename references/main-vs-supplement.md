# Main-text and Supplement triage

Use this reference when the Results section is crowded or when deciding whether to relocate an
existing figure, table, paragraph, or detailed comparison. This is a decision guide, not an automatic
word-count target. A journal may prescribe additional requirements; verify them for submission work.

## Purpose-first placement test

Start with the experiment's stated purpose and the conclusion the Results section can support.
Classify each item by its *role in that argument*, not by whether the values are called raw,
intermediate, or final. Here, `intermediate data` means an intermediate calculation, constructed
index, processing step, or secondary diagnostic. It does not mean a causal mediation analysis;
a measured mediator may itself be a central study outcome.

Ask the following in order:

1. **Direct answer:** Does this finding directly answer the stated experimental purpose? If yes,
   keep the finding and decisive evidence in the main Results. Do not relocate the only result that
   establishes the section's conclusion.
2. **Essential support:** Even if intermediate, is this contrast needed to establish or interpret
   that answer, distinguish competing explanations, or show an exception that changes it? If yes,
   keep a concise version with a key numerical anchor in the main text. Full supporting detail may
   be supplementary.
3. **Supporting detail:** Does the item mainly document a calculation stage, full case-level values,
   robustness grid, implementation check, or repeated example whose role is already clear from the
   main result? If yes, it can move to the supplement if the main text keeps a specific pointer.
4. **Traceability:** Does the target supplementary figure/table actually exist, with matching
   population, metric, model, units, precision and version? If no, mark the move as conditional and
   retain the main evidence until the destination is built and verified.

A primary experiment can have a large table: condense it into a main figure or compact table that
still proves the purpose, then put complete rows in the supplement. Intermediate status alone does
not justify moving material. Do not hide contradictory results, important null findings, exceptions,
or substantial missingness in the supplement. Do not promote a result merely for a small p-value.

## Typical allocation

| Main Results | Supplementary material |
|---|---|
| The result directly answering the experimental purpose | Full row-level values behind the retained main result |
| Decisive comparisons, conditions, and supported uncertainty | Additional settings or parameter-grid details |
| An intermediate contrast essential to interpreting the answer | Complete calculation stages, constructed-index components, and implementation checks |
| An exception that changes the main conclusion | Further examples with the same interpretation |
| A readable figure/table needed to verify the central claim | Extended diagnostics and secondary figures/tables |

These are placement tendencies, not fixed content types. An intermediate measure can stay in the
main text when it is the evidence on which the main claim depends. Conversely, a table of final
outcomes can be supplementary when a compact main figure already shows the decisive result.

## How to move material safely

- Produce a location-specific map: item, current source, proposed destination, reason, concise main
  replacement, and target supplement label. Distinguish `retain`, `condense`, `move`, and `delete as
  repetition`. Review-only output is a proposal; direct implementation follows the user's scope.
- Ensure the supplementary target exists or create it when authorized. Preserve the original
  conditions, denominators, numerical precision, definitions, sample exclusions, caption, legend,
  table notes, and relevant citations. Maintain figure/table numbering and labels consistently.
- Leave a useful pointer in the main text: the main finding and one or two decisive anchors, followed
  by the exact `Supplementary Fig. Sx` or `Supplementary Data Table Sx` reference. A bare `see
  Supplementary Material` is insufficient for a central comparison.
- Recheck all references from the final main manuscript to the final supplement, as well as their
  model/data versions. A previously generated supplement does not prove current alignment.
- When the underlying supplement data are unavailable, propose a move conditionally and keep the
  central evidence in the main text until a valid destination is built and verified.
